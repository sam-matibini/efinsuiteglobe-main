# Memory: features/accounting/aspe-soce-implementation
Updated: now

The Statement of Changes in Equity (SOCE) follows ASPE standards using a movement-based schema and a columnar format. Share Capital balances are calculated by aggregating ALL accounts with `equity_category = 'COMMON_STOCK'` (not just a single account), summing their opening balances and GL activity. This multi-account aggregation is critical because organizations typically have multiple COMMON_STOCK accounts (e.g., "Common Stock" and "Additional Paid-In Capital"). The `populate_equity_movements` RPC now generates movement rows for both Retained Earnings and all Common Stock accounts, with fiscal-year-aware date boundaries derived from the organization's `fiscal_year_end_month`. Opening balances for Retained Earnings are derived from the `get_retained_earnings_rollforward_series` RPC. The fallback name-matching system identifies accounts using patterns like 'common share', 'retained earning', or 'dividend' when `equity_category` is not set.
